## Do not include local artifacts

| Path/category | Reason it is unnecessary for a teammate's checkout |
| --- | --- |
| `.env`, `.env.test`, other private environment files | They contain workstation-specific credentials. Teammates copy the committed examples and set their own values. |
| `.local/`, including reference-source cache, backups, logs, tools venv and runtime JAR copies | Generated/private artifacts. The documented fetch/preparation scripts recreate reference caches, dependencies recreate the venv, and Maven rebuilds the JAR. Database dumps can contain private data and must not substitute for migrations. |
| `frontend/node_modules/`, frontend `dist/`, backend `target/` | Rebuilt with the lockfile and Maven wrapper; not source dependencies. |
| `.idea/`, `.DS_Store`, editor settings | Workstation metadata, not runtime requirements. |
| Browser reports, screenshots generated by this run, cookies and raw logs | Validation output may contain synthetic identities/session details; the sanitized report records results. Keep existing deliberately reviewed tracked evidence. |
| `scripts/test-local.py` | Pre-existing untracked workstation helper with local/container assumptions and Chinese output. It is not referenced by the documented startup or CI path; committed `scripts/check.sh` and `.env.test.example` provide the portable route. Leave this local file intact. |
| The temporary handover checkout and its Docker database | Verification resources only. Teammates create their own empty database and migrate/import it using the guide. |

Do not use `git add .` without reviewing untracked files; in particular, `scripts/test-local.py` remains visible as untracked. Stage only the explicit proposed paths after reviewing the diff. The deleted Chinese guide and its new English filename form one intended rename.
