Implemented frontend/src/domain/media.ts, features/entry/media/Recorder.ts and api/speech.ts. Class construction/support checks never request a microphone. Explicit start first checks secure context, getUserMedia and runtime MediaRecorder.isTypeSupported against only server-accepted audio WebM/MP4 candidates. It requests audio:true, records with selected MIME and verifies actual recorder/chunk types; never relabels WebM as WAV. Browser support is checked at runtime; no claim is made for an untested browser/version.

One capture owns stream/tracks, native listeners, chunks, completion and timers. Stop is idempotent while finishing and waits for final dataavailable before stop, preserving chunk order. Tracks stop immediately on stop request; final listeners remain for finalization, with5second watchdog. Chunks are capped8MiB; max configured duration is capped60seconds (automatic finalization starts at59.75s to allow event-loop/codec padding, without capping reported actual duration); an overdue background stop is rejected rather than lying about recorded duration. Empty audio, device-ended/native error, denial/no-device/constructor/start failure and unsupported actual MIME have safe actionable states. All tracks/listeners/timers/Blob chunks are released on complete/error/cancel/dispose. Cancel while permission is pending clears local waiting; a stream granted later is stopped immediately without stale UI publication. Replacing an in-flight permission request cannot publish an old result. dispose does not notify unmounted UI, rejects new starts and ignores late native events. No ObjectURL, upload, business draft or persistence is created by Recorder.

transcribeAudio posts only the actual typed Blob in audio FormData with matching generated audio.webm/audio.mp4 extension, Session/CSRF transport, signal and80second client deadline (up to10second server decode plus60second provider processing and transport margin). It rejects size/MIME/duration/mismatch before dispatch and validates nonblank≤10000transcript/control-safe output using generated schema. No transcript placeholder, raw private error or record write. A06 must mount/use this lifecycle and abort uploads on owner/route changes.
